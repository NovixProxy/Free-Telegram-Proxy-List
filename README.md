## ✨ About

Novix Proxy is an open-source directory of public Telegram Web Proxy links, designed to help users discover available proxies and connect to Telegram easily.

## ⚡ Features

- Automated HTTPS endpoint monitoring
- Regularly updated proxy information
- One-click Telegram connection
- Country-based proxy organization
- Connection status and latency display
- Dynamic pinned proxy ordering
